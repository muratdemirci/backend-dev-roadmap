# Basic Frontend Knowledge

As a backend developer, having a fundamental understanding of frontend technologies helps you collaborate effectively with frontend teams and build better APIs and services.

## Topics

- [HTML Basics](./html-basics) — Structure of web pages
- [JavaScript Basics](./javascript-basics) — Programming logic for the web
- [CSS Basics](./css-basics) — Styling and layout of web pages

## Why Backend Developers Should Know Frontend Basics

- **Better API Design** — Understanding how frontends consume data helps you design cleaner APIs.
- **Debugging** — You can trace issues across the full stack.
- **Full-Stack Capability** — Many teams expect backend developers to handle simple frontend tasks.
- **Communication** — Speaking the same language as frontend developers improves collaboration.
